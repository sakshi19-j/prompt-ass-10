# PlacePrep

PlacePrep is an offline placement preparation portal built with semantic HTML, CSS, and vanilla JavaScript. It has no frameworks, package installation, or external network dependencies.

## Run locally

1. Open the `placement-portal` folder in VS Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Use the shared navigation to explore the five pages.

The pages can also be opened directly in a browser, though Live Server provides the smoothest local development experience.

## Features

- Responsive home page with preparation overview, feature cards, and stats.
- Ten-question aptitude quiz with categories, progress feedback, score review, and restart.
- Fifteen filterable coding interview questions with search, topic, and difficulty controls.
- Keyboard-accessible interview tip accordion.
- Preparation checklist grouped by topic with localStorage persistence and reset.
- Shared responsive navigation with mobile menu, active-page highlighting, and saved light/dark theme.
